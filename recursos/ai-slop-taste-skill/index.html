Recurso gratis

Cómo quitar el AI slop de tus webs con Taste Skill

Si le pedís una web a Claude Code, Cursor o Codex, casi siempre te devuelve la misma landing: gradiente violeta, tres cards iguales y un “Scroll to explore”. Esta guía te muestra cómo cambiar eso con una skill gratuita.

Instalación, los prompts que uso y el checklist completo de lo que Taste Skill no deja pasar. Sirve para webs nuevas y para limpiar las que ya hiciste.

01 · El problema

Qué es el AI slop y por qué todas las webs hechas con IA se parecen

AI slop es el diseño “promedio” que sale cuando le pedís una web a un agente sin darle criterio. El modelo arma lo más probable, y lo más probable es lo que ya viste mil veces. El cliente no sabe nombrarlo, pero lo siente: la web se ve barata y genérica.

Lo que te devuelve la IA sola

  • Gradientes violetas y manchas de color de fondo
  • Tres cards iguales para “features”
  • Dashboards y terminales falsos armados con divs
  • Etiquetas tipo “BETA”, “V0.6” o “00 / INDEX”
  • “Scroll to explore” y flechitas hacia abajo

Lo que buscás

  • Una dirección de arte que salga del cliente
  • Fotos reales en vez de ilustraciones genéricas
  • Jerarquía clara: título que se entiende en la primera pantalla
  • Márgenes parejos, sin huecos al azar
  • Que se vea bien en celular, no sólo en desktop
02 · La herramienta

Qué es Taste Skill

Taste Skill es una skill gratuita y open source (licencia MIT), creada por Leon Lin, que hace que los agentes de código diseñen webs en vez de ensamblar la landing promedio. Le da al agente una dirección de arte, fotos reales y una forma de revisar su propio trabajo en un navegador de verdad.

Está armada a partir del estudio de 247 sitios curados. Cuando construye una página sigue seis pasos:

  1. Lee el brief y anota lo que sólo tiene ese cliente.
  2. Reparte tres de 20 direcciones de diseño investigadas y el agente elige una.
  3. Encuentra la idea: una frase que une el material del cliente con esa dirección.
  4. Construye con fotos y videos reales de colecciones abiertas, con sus créditos.
  5. Revisa la página en un navegador real en tres anchos de pantalla y la reprueba si tiene slop.
  6. Mira sus propias capturas y corrige los tres problemas principales, hasta tres rondas.

Funciona con Claude Code, Codex, Cursor y cualquier herramienta que lea archivos SKILL.md. Sirve con React, Vue, Svelte o HTML puro, porque las reglas son de diseño, no de framework.

03 · Antes de empezar

Qué necesitás

  • Node 22 o más nuevo. Lo chequeás con node -v en la terminal.
  • Chrome, Edge o Chromium instalado: la skill lo usa para revisar la página.
  • Internet, sólo para buscar las fotos.

No necesita API keys ni instala nada extra en tu proyecto.

04 · Instalación

Cómo instalarla

Opción A, cualquier agente. Desde la carpeta de tu proyecto, en la terminal:

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

Opción B, plugin de Claude Code. Escribí esto dentro de Claude Code, un comando por vez:

/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill@taste-skill

Para actualizarla más adelante usás /plugin update. Si trabajás con Codex, el equivalente es codex plugin marketplace add Leonxlnx/taste-skill y después codex plugin add taste-skill@taste-skill, y abrís una sesión nueva.

05 · Web nueva

Cómo usarla en una web desde cero

La clave es el brief. Cuanto más te cuente del cliente, más se aleja de lo genérico, porque la skill arranca buscando lo que es único de ese negocio. Este es el formato que uso (completalo con tu cliente):

Prompt de ejemplo 
Usá la skill design-taste-frontend para diseñar y construir la web de este cliente.

Cliente: [nombre y rubro, ej. cafetería de especialidad en Palermo]
Qué lo hace único: [historia, producto estrella, barrio, materiales, lo que nadie más tiene]
A quién le habla: [cliente ideal]
Objetivo de la web: [reservas, consultas por WhatsApp, ventas]
Secciones: [inicio, servicios, sobre nosotros, contacto]
Material que tengo: [logo, fotos propias, textos, colores de marca]
Lo que NO quiere: [ej. nada que parezca una startup tech]

Tené paciencia: una construcción completa tarda entre 30 y 45 minutos y consume unos cientos de miles de tokens, porque la skill se revisa y corrige sola varias veces.

06 · Web que ya tenés

Cómo limpiar una web que ya hiciste

Si la web ya existe, la skill primero la audita en un navegador real y después cambia. Así no te rompe lo que funciona:

Prompt de ejemplo 
Usá la skill design-taste-frontend para auditar esta web en el navegador y sacarle el AI slop.
Primero listame los problemas que encontrás, ordenados por impacto.
Mantené el contenido, la estructura de páginas y los colores de marca. Cambiá la parte visual.

También sirve para dashboards y paneles: desde la versión 2.1 detecta si es una página o una app y aplica reglas propias (paneles tranquilos, números alineados, color sólo para los datos).

07 · El checklist

Lo que Taste Skill no deja pasar

Estas son algunas de las prohibiciones de la skill. Aunque no la uses, sirven como checklist para revisar cualquier web antes de entregarla:

✕

Gradiente violeta de IANi manchas de color tipo “mesh”, salvo que la marca sea violeta de verdad.

✕

Tres cards igualesLa fila de tres features idénticas como solución por defecto.

✕

UI falsa con divsDashboards o terminales de mentira para “mostrar el producto”.

✕

Etiquetas de versión“V0.6”, “BETA” o “INVITE-ONLY” en el hero, salvo que sea un lanzamiento.

✕

Numeración decorativaTítulos tipo “00 / INDEX” encima de cada sección.

✕

“Scroll to explore”Ni flechitas que te piden bajar.

✕

Píldoras sobre las fotosEl texto va debajo de la imagen, no encima.

✕

Puntitos de “estado” de adornoSólo si muestran un estado real, y como mucho uno por sección.

✕

Tiras de ciudad, hora o climaDatos de relleno que no le importan a nadie.

✕

Ilustraciones SVG genéricasDibujos hechos a mano por la IA como decoración por defecto.

✕

Rayas largas de IA en el textoLas rayas (—) que delatan copy generado. Se usa guion o se reescribe la frase.

✕

Bordes arriba y abajo en cada filaListas y tablas largas llenas de líneas.

Además pone límites al hero: el título en dos líneas como máximo en desktop, el subtítulo en hasta veinte palabras y el menú en una sola línea.

08 · Para cerrar

Tres consejos para que el resultado sea tuyo

  • Cambiá las fotos. La skill usa imágenes de colecciones abiertas (Wikimedia Commons, Openverse, el Met) con sus créditos. Son un gran punto de partida, pero cuando tengas las fotos reales del cliente, reemplazalas.
  • El brief manda. Si el resultado se ve genérico, casi siempre es porque el brief lo era. Sumá detalles concretos del negocio y volvé a correrla.
  • Revisá en celular. La skill ya chequea tres anchos de pantalla, pero dale una pasada vos desde tu teléfono antes de mostrársela al cliente.
